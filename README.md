# TP2-WEB-NestJs

This repository contains the source code and deliverables for the second practical assignment (TP2) in the **NestJS framework**.

The project focuses on implementing and exploring NestJS features through practical exercises, including REST API development, middleware, routing, and database integration.

## Technologies Used

- **NestJS** – Node.js framework for building server-side applications.
- **TypeScript** – Main programming language.
- **Node.js** – JavaScript runtime environment.
- **SQLite** – Relational database.
- **TypeORM** – Object-relational mapping (ORM).

## Project Setup

Clone the repository:

```bash
git clone https://github.com/HamzaKacem2004/TP2-WEB-NestJs.git
```

Navigate to the project directory:

```bash
cd cv-manager
```

Install dependencies:

```bash
npm install
```

## Running the Application

```bash
# Development mode
npm run start

# Watch mode
npm run start:dev

# Production mode
npm run start:prod
```

## Project Structure

The application follows the modular architecture provided by NestJS, organizing its components into modules, controllers, services, and other application resources.
